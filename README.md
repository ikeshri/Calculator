# Calcora Web

Static, mobile-first all-in-one calculator website for GitHub Pages.

## Run locally
Open `index.html`.

## GitHub Pages
Push these files to the repository root, then enable:
Settings → Pages → Deploy from branch → `main` → `/ (root)`.

## Included
- 80 calculator entries
- Search, categories, favorites, history
- Dark/light theme
- Offline-first local calculators
- Currency online tool (Frankfurter)
- Crypto market snapshot (CoinGecko)
- Fuel cost tool
- Mobile-first responsive UI
- `_ikeshri` developer branding

Some specialized calculators intentionally use simplified formulas and should be reviewed before financial/tax/medical production use.
